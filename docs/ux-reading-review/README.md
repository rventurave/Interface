**Segunda revisión UX: Reading Is Unnatural — 19 de noviembre de 2026**

El cumplimiento global sigue siendo **parcial**. Se corrigieron problemas de presentación comprobados en navegador. Persisten dificultades de lectura del mapa, textos de los datos y respuestas simuladas, y la dependencia del menú contextual. Se mantuvieron la paleta oscura, la estructura del demo y su comportamiento.

La evaluación fue heurística y técnica; no constituye una prueba de comprensión con usuarios ni una certificación completa de accesibilidad. «Cumple» se utiliza solo para comprobaciones concretas con evidencia. «Parcial» significa que quedan incumplimientos dentro de la regla, aunque otros aspectos sí cumplen.

Para el contraste se empleó el criterio de **4,5:1 para texto normal** y **3:1 para texto grande**. El criterio también aplica a placeholders; los controles inactivos tienen una excepción. [WCAG 2.2, explicación oficial de 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). El tamaño de 16 px es una decisión de legibilidad, no una certificación AA por sí mismo.

La comprobación a 320 px distingue la página y sus paneles de los diagramas bidimensionales. Que la página no desborde horizontalmente no demuestra por sí solo que no existan superposiciones; por ello también se comprobaron coordenadas y capturas. [WCAG 2.2, explicación oficial de redistribución 1.4.10](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html).

**Evidencia y límites de las mediciones**

- [Mediciones antes y después](evidencia/mediciones.json): tamaño de viewport, muestras mínimas de contraste y tipografía, placeholders, texto recortado y límites de menús por estado. Los cocientes se calcularon con colores CSS y fondos compuestos; en porcentajes SVG del HTML se utilizó el relleno del círculo de fondo. No se infiere contraste a partir de una captura.
- [Comprobaciones geométricas adicionales](evidencia/disposicion-adicional.json): cabecera, chat, barra y lienzo sin superposición en 320 y 390 px. El diálogo en **320 × 360** queda entre **(16,16) y (304,344)**; su contenido puede desplazarse y el botón de creación sigue siendo accesible mediante ese desplazamiento.
- [Artículos en escritorio](evidencia/after-articles-selected-1440.png) y [en móvil](evidencia/after-articles-selected-320.png): evidencia del detalle legible y del problema pendiente de escala del mapa.
- [Confirmación final del diálogo](evidencia/modal-final.json): contraste, métricas del campo y conservación de `resize: none` en 320 y 1440 px.
- Las capturas generales son de página completa; las del diálogo muestran el viewport. No implican que todos los elementos de una pantalla entren simultáneamente en la altura del dispositivo.
- La muestra no cubre todos los textos posibles, todos los fondos de superposición de los mapas ni el comportamiento de todos los navegadores. No se atribuye cumplimiento total a ninguna de las cinco reglas globales mientras persistan los problemas descritos.

**Conservación del funcionamiento**

La [verificación de código](evidencia/verificacion-codigo.json) compara **50 archivos** con el estado al comenzar esta revisión: **38 son idénticos byte a byte** y **12 contienen cambios de presentación o redacción**. Se conservan hooks, datos, tipos, utilidades, estados, condiciones, manejadores, navegación, simulaciones, dependencias y configuración.

La comparación del AST de TypeScript excluye únicamente atributos de presentación/nombres de campos, redacción visible y la nueva ayuda estática. Los scripts del HTML solo cambian **dos valores de posicionamiento CSS**, `menu.style.left` y `menu.style.top`; el resto del JavaScript coincide. Las asignaciones siguen usando las mismas coordenadas del mismo evento, acotadas mediante CSS, sin incorporar lógica de eventos.

`npm run build` y `git diff --check` finalizaron correctamente. Los 84 estados muestreados no registraron errores de ejecución. Estas comprobaciones verifican compilación y preservación del código; no aseguran que las funciones incompletas del demo estén implementadas o sean correctas.
